# ร้านของฉัน – พอร์ตโฟลิโอสินค้า (ขายสินค้า / รับของ)

เว็บไฟล์เดียว (HTML + CSS + JavaScript ในไฟล์เดียว) สำหรับจัดป้ายสินค้า ตั้งราคา จำนวน เซ็ตโปรโมชั่น และสร้างภาพสำหรับโพสต์ขายของ ไม่ต้องติดตั้งหรือคอมไพล์อะไรเพิ่ม

## ฟีเจอร์

มี 2 หน้า สลับด้วยแท็บด้านบน ข้อมูลของสองหน้าแยกกัน

- **ขายสินค้า** อัปโหลดรูปหลายรูปพร้อมกัน แต่ละรูปเป็นป้ายสินค้า ใส่ชื่อ ราคา จำนวนที่มี (ปุ่ม − / +) และคำอธิบายพร้อมแถบอิโมจิ
- **รับของ** ใช้งานเหมือนหน้าขาย แต่เป็นสินค้าที่ต้องการรับ (ราคารับ จำนวนที่ต้องการรับ) และไม่แสดงส่วนลดในเซ็ต
- **เซ็ตโปรโมชั่น** ติ๊กเลือกสินค้าแล้วสร้างเซ็ตได้ เซ็ตสินค้าชิ้นเดียวคิดราคา × 12
- **เลือกก่อนทำ** ติ๊กเลือกที่ป้าย แล้วใช้แถบเครื่องมือด้านล่างเพื่อสร้างภาพโพสต์ สร้างเซ็ต หรือลบที่เลือก
- **โลโก้และแถบอัปเดต** โลโก้น้องแมวมุมซ้ายบน (ใช้เป็นไอคอนแท็บด้วย) และแถบอัปเดตด้านขวาที่ข้อความเลื่อนต่อเนื่อง แสดงจำนวนสินค้า/เซ็ต และกิจกรรมล่าสุด เช่น เพิ่มสินค้า ปรับราคา ปรับจำนวน (เอาเมาส์วางเพื่อหยุดเลื่อน)
- **พื้นหลังธีมร้านสัตว์เลี้ยง** ลวดลายสัตว์มีหาง (แมว หมา กระรอก กระต่าย ปลา) กับรอยเท้า วาดด้วย SVG ในไฟล์ ไม่ต้องใช้รูปภายนอก
- **ภาพโพสต์** แยกภาพสินค้าเดี่ยวกับภาพเซ็ต เลือกสีพื้นหลังหรืออัปโหลดรูปพื้นหลังได้ พร้อมข้อความประกอบโพสต์ให้คัดลอก

## วิธีนำขึ้น GitHub

### วิธีที่ 1: อัปโหลดผ่านเว็บ (ง่ายที่สุด)

1. ไปที่ https://github.com/new ตั้งชื่อ repository เช่น `portfolio-shop` แล้วกด **Create repository**
2. กด **uploading an existing file** แล้วลากไฟล์ทั้งหมดในโฟลเดอร์นี้ไปวาง (`index.html`, `README.md`, `.gitignore`, `.nojekyll`)
3. กด **Commit changes**

### วิธีที่ 2: ใช้ Git

```bash
cd portfolio-shop
git init
git add .
git commit -m "first commit"
git branch -M main
git remote add origin https://github.com/<ชื่อผู้ใช้>/portfolio-shop.git
git push -u origin main
```

## เปิดเป็นเว็บด้วย GitHub Pages

1. เข้า repository แล้วไปที่ **Settings → Pages**
2. ที่ **Source** เลือก **Deploy from a branch**
3. เลือก Branch เป็น `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
4. รอประมาณ 1–2 นาที เว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/portfolio-shop/`

## ข้อควรรู้

- **ข้อมูลเก็บในเบราว์เซอร์ของแต่ละเครื่อง** (localStorage) สินค้า รูป และเซ็ตจะไม่ตามไปเมื่อเปลี่ยนเครื่อง เปลี่ยนโดเมน หรือล้างข้อมูลเบราว์เซอร์ และคนอื่นที่เปิดลิงก์จะเห็นหน้าว่างของตัวเอง ไม่ใช่ร้านของคุณ
- รูปที่อัปโหลดจะถูกย่อให้ยาวด้านละไม่เกิน 640 พิกเซลก่อนเก็บ เพื่อให้เก็บได้หลายรูป ถ้าพื้นที่เต็มจะมีข้อความแจ้งเตือน
- ฟอนต์ Prompt และ Sarabun โหลดจาก Google Fonts ต้องมีอินเทอร์เน็ต ถ้าออฟไลน์จะใช้ฟอนต์สำรองของเครื่อง
- ปุ่ม “บันทึกเป็นรูปภาพ” ดาวน์โหลดไฟล์ PNG โดยตรง

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวเว็บทั้งหมด |
| `README.md` | คู่มือนี้ |
| `.nojekyll` | บอก GitHub Pages ให้เสิร์ฟไฟล์ตามที่เป็น ไม่ผ่าน Jekyll |
| `.gitignore` | รายการไฟล์ที่ Git ไม่ต้องเก็บ |
